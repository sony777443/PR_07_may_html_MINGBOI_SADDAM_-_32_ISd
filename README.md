# Английский для путешествий за 3 месяца | TravelSpeak

Лендинг онлайн‑курса английского языка для путешественников. Проект демонстрирует основы веб‑разработки: HTML, встроенную CSS‑стилизацию и базовую интерактивность на JavaScript.

## О проекте

Это одностраничный сайт (лендинг), рекламирующий интенсивный онлайн‑курс английского языка «TravelSpeak». Цель курса — помочь пользователям освоить базовый разговорный английский для поездок за границу.

## Ключевые особенности

* **Адаптивный дизайн** (изображения масштабируются на 100 % ширины).
* **Встроенная CSS‑стилизация** для фона и элементов формы.
* **Интерактивная форма** с валидацией (обязательные поля) и обработкой отправки на JavaScript.
* **Структурированный контент** с разделами о курсе, его преимуществах и программе.
* **Призывы к действию** (кнопка «Получить программу курса», форма записи со скидкой).

## Содержимое репозитория

* `index.html` — главная страница лендинга с полной структурой и функционалом.
* `travel.jpg` — фоновое изображение (пара в аэропорту с чемоданами).
* `travel2.png` — иллюстрация интерфейса платформы обучения.

## Разделы лендинга

1. **Главный экран** — заголовок, описание курса, изображение, кнопка для получения программы.
2. **О курсе** — длительность, формат, график, доступ к материалам.
3. **Почему выбирают нас** — преимущества: разговорная практика, преподаватели‑носители, гибкий график, чат‑практика, гарантия результата.
4. **Программа курса** — тематическое разбиение по месяцам.
5. **Акция** — призыв начать обучение со скидкой 15 % для первых 20 записавшихся.
6. **Форма записи** — сбор контактов пользователя (имя, возраст, пол, телефон).
7. **Контакты** — телефон, email, ссылки на соцсети (Telegram, VK).
8. **Футер** — копирайт школы «TravelSpeak» (2026).
